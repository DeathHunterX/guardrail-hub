# Examples
## Worked, Concrete Illustrations

Status: **Stub** — contract fixed in [Phase 1](../foundation/architecture.md#examples). No dedicated phase currently defines this module further.

## Purpose
Show, not tell. A worked example grounds a [Skill](../skills/README.md) or [Standard](../standards/README.md) in real, current Guardrail Hub code, reducing the ambiguity a prose description alone would leave.

## Responsibility
Stay grounded in code that actually exists in the repository right now — an example that has drifted from the current codebase is worse than no example, because it's presented with the same confidence as one that hasn't.

> **Frontmatter:** example units carry frontmatter validated against [schema/base.schema.json](../schema/base.schema.json); an Example-specific extension schema is authored when this module gets its first real unit, per [schema/README.md](../schema/README.md).

## Inputs
A completed, correct task.

## Outputs
A citable example other units can reference.

## Dependencies
[Knowledge](../knowledge/README.md), [Skills](../skills/README.md), [Standards](../standards/README.md), [Templates](../templates/README.md).

## Consumers
[Agents](../agents/README.md), [Skills](../skills/README.md) (linked as illustration).

## Owner
The domain owner.

## Lifecycle
Pruned once the example no longer matches current code — not left to accumulate as silent drift. No examples exist yet.

# Guardrail Hub — AI Operating System (AIOS)

This is the human and first-contact index for the AIOS. Ordinary product tasks do not load it as Tier 0: after first contact they load only Tier G (`guardrails/core.md`) and the actual Tier 0 (`router/MANIFEST.md`), as defined by the [Kernel context budget](kernel/README.md#context-budget--loading-strategy). This file points to the system; it is not itself runtime context for every task.

If you are new to this repository, follow [foundation/bootstrap.md](foundation/bootstrap.md) once. For subsequent work, use the Product or Meta lane in [`AGENTS.md`](../AGENTS.md) and load only the addresses that lane names.

`review/`, `evaluation/`, and `governance/` are meta-modules — they govern the AIOS's own quality and evolution rather than serving product tasks directly. They were added additively per [Architecture: Expansion Strategy](foundation/architecture.md#expansion-strategy) and sit as peers to the original twelve, not replacements for any of them.

`intelligence/` is different again: unlike every other module above, it isn't a process framework — it's actual content, generated by inspecting the real repository. See [intelligence/README.md](intelligence/README.md#relationship-to-the-aios) for exactly how it relates to [knowledge/](knowledge/README.md).

"Stub" means the module's contract is fixed but no framework/content has been authored. "Specified" means the framework exists but has no Active content units. "Populated" means real units or records exist. The generated category indexes and unit frontmatter are authoritative for exact counts and lifecycle state.

## Principles in One Line

Single source of truth. Minimal necessary context. Model-agnostic. Deterministic discoverability. Knowledge, policy, and action stay separate. Traceability over confidence. Additive evolution. Human authority is final.

Full reasoning behind each: [foundation/vision.md](foundation/vision.md#4-principles-that-must-never-be-violated).

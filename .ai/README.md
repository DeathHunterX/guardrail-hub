# Guardrail Hub — AI Operating System (AIOS)

This is the entry point every AI assistant loads first, in full, before reasoning about any task. It is small by design — Tier 0 of the [context budget](kernel/README.md#context-budget--loading-strategy) — and exists to point to everything else, not to contain everything else.

If you are an AI assistant starting a session in this repository: read this file, then [kernel/README.md](kernel/README.md), then follow the Kernel's startup sequence. Do not read the rest of `.ai/` up front — it is addressed, not preloaded.

`intelligence/` is different again: unlike every other module above, it isn't a process framework — it's actual content, generated by inspecting the real repository. See [intelligence/README.md](intelligence/README.md#relationship-to-the-aios) for exactly how it relates to [knowledge/](knowledge/README.md).

"Stub" means the module's *contract* is fixed (see [foundation/architecture.md](foundation/architecture.md#module-contracts)) but no framework or content has been authored yet. "Specified" means the framework is designed but has zero content units. "Populated" means real content exists — currently only `intelligence/`. Loading a stub's README costs nothing; there's nothing behind it yet.

## Principles in One Line

Single source of truth. Minimal necessary context. Model-agnostic. Deterministic discoverability. Knowledge, policy, and action stay separate. Traceability over confidence. Additive evolution. Human authority is final.

Full reasoning behind each: [foundation/vision.md](foundation/vision.md#4-principles-that-must-never-be-violated).

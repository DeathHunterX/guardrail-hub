# Backend Domain Router — Tier 1

> Reached from [router/MANIFEST.md](../../router/MANIFEST.md) when a task is classified into the **Backend** Domain. Holds this Domain's Agent registry and maps Backend task-subtypes to the Category Indexes / units to load. A materialized routing artifact (no frontmatter, not a unit) — see [router/README.md](../../router/README.md). Created in M3 ([Decision 0001](../../decisions/0001-aios-bootstrap-roadmap.md)).

## Agent Registry (Backend Domain)

| Agent | Owns | Contract |
|---|---|---|
| Backend Agent | `mcp-server/**` | [backend-agent.md](backend-agent.md) |

One agent today. Additional Backend agents (e.g. a dedicated Data agent) register here as peers — flat authority, per [agents/README.md](../README.md#capability-hierarchy-known-future-domains).

Standards are addressed via their Category Index (generated by `aios index`); the Router resolves *addresses*, and Kernel/Loading fetches the named units lazily. The Backend Agent's `standards_enforced` frontmatter is the authoritative list; this table is the task-shaped view of it.

**Before introducing any new type that represents a business concept**, check it against the canonical vocabulary in [Decision 0008](../../decisions/0008-domain-ubiquitous-language.md) — `Severity`, `Finding`, `FindingIdentity`, `FindingSummary`, `Confidence`, `OperationPhase` already exist and must be reused, never redefined ([domain-layer](../../standards/architecture/domain-layer.md) D1/D4). A concept genuinely absent from that vocabulary is a Decision-level change requiring an ADR, not a new class.

## Escalation Out of Domain
A task touching `web/`, `mobile/`, deployment/infra, or AIOS meta-work is out of Backend's Decision Authority — delegate or escalate per [agents/README.md](../README.md#collaboration-model). This Domain Router does not resolve those.

# Review Passes

Records of executed [Review Framework](../README.md) passes — each captures the five required outputs (Summary, Risk Analysis, Violations, Recommendations, Approval Decision) for the asset(s) reviewed. Established in Roadmap M4 ([Decision 0001](../../decisions/0001-aios-bootstrap-roadmap.md)), when the Review process ran for the first time.

A pass may cover one asset or a coherent batch (e.g. all units authored in one milestone slice). Append-only.
